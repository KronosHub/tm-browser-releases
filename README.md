# TM Browser — versioni

App macOS per sfogliare i backup Time Machine (di questo Mac e sui NAS) e recuperare file.
Questo repository contiene solo le versioni compilate: l'app le usa per aggiornarsi da sola.

## Installazione

1. Scarica `TM-Browser.zip` dall'[ultima Release](../../releases/latest), estrai e sposta `TM Browser.app` in `/Applications`.
2. Primo avvio: clic destro sull'app › **Apri** (è firmata con un certificato interno, non notarizzato da Apple).
3. Impostazioni di Sistema › Privacy e sicurezza › **Accesso completo al disco** › aggiungi TM Browser.

Gli aggiornamenti successivi arrivano dall'app (TM Browser › Verifica aggiornamenti…) e mantengono i permessi.

Requisiti: macOS 14 o successivo.
